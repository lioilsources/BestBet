# M0: validace dat (hokej)

Plán: [Prompts/00-VLNA_PLAN.md](../Prompts/00-VLNA_PLAN.md) §1.4.5, §1.4.7, §6. Výstup: `DATA_M0.md` (generuje `ingest-hockey report`).

## Zdroje a jak se slučují

| Zdroj | Co dává | Role | Stav |
|---|---|---|---|
| API-HOCKEY (api-sports.io) | zápasy, třetiny, OT/SO, fáze (`week`), kurzy 28 knih | primární pro zápasy | kód hotový, **neověřený bez klíče** |
| stats.swehockey.se | rozpis + výsledky (třetiny, OT, SO), zápis s brankáři (SV, střely, GK In/Out → starter a TOI) | sekundární, jediný zdroj brankářů pro Allsvenskan | **ověřeno na živých datech** |
| OddsPapi v4 | fixtures, katalog trhů, historie kurzů (≤ 3 knihy na dotaz, cooldown 5 s) | historie kurzů | kód hotový, **neověřený bez klíče** |
| ceskyhokej.cz / hokej.cz | brankáři Maxa ligy a Extraligy | sekundární | **chybí**, další krok |

Pravidla slučování (`internal/store`):
- API-HOCKEY zápas přepisuje vše. Swehockey jen doplní prázdná pole a přidá `swehockey_id`.
- Týmy se párují přes alias, pak přesný normalizovaný název, pak jednoznačnou fuzzy shodu tokenů (`Östersunds IK` ≈ `Ostersund`). Fuzzy shoda se uloží jako alias do `team_aliases`.
- Zápas se páruje přes stejnou dvojici týmů v okně ±36 h, vybere se nejbližší.
- Kurzy z OddsPapi týmy nezakládají. Neznámý tým znamená nespárovaný fixture v `fixture_links`; z toho se počítá join rate (cíl ≥ 98 %).
- B/J20 týmy ve stejné lize jako A tým potřebují ruční alias (`aliases:` v `config/leagues.yaml`).

## Zjištění z rešerše a implementace

- **OddsPapi historie kurzů začíná 01/2026.** Tři sezony kurzů tam nejsou; pro backtest 2023/24–2024/25 je potřeba jiný zdroj (Betexplorer archiv jen interně, nebo vlastní snapshoty od teď).
- **API-HOCKEY `/odds` drží jen nadcházející a nedávné zápasy.** Historie kurzů z něj vznikne jen sběrem snapshotů (`ingest-hockey snapshot` v cronu). Na free tieru je 100 požadavků za den, proto má klient rozpočet (`APIHOCKEY_BUDGET`) a vše cachuje na disk.
- Free plány api-sports v minulosti omezovaly přístup ke starším sezonám. Pokud API vrátí chybu `plan`, zobrazí se v logu doslova.
- Swehockey: rozpis play-off 2025/26 (Slutspel, Play Out) nemá odkaz na zápis zápasu, takže **brankáři tam chybí** (starší play-off je mají). ID zápasu je tam kód utkání (`9013…`), ne ID zápisu.
- Swehockey: víc prodloužení v play-off se sčítá do `ot_home/ot_away`. V základní části je pátá položka nájezdy.
- `pre_playoff` se z popisků určit nedá, potřebuje tabulku. Nastaví se v M1.
- Série: `series_id = liga:sezona:týmA-týmB:n`; nová série začíná po mezeře > 10 dní. `series_score_before` je z pohledu domácího týmu.

## První běh (2026-11-05, jen swehockey, bez klíčů)

HockeyAllsvenskan 2023/24–2026/27: 1 352 odehraných zápasů, všechny výsledky naparsované (vč. play-off s víc prodlouženími). Oba startující brankáři jsou u 1 208 z 1 210 zápasů základní části, celkem 96 % zápasů. Průměrná úspěšnost zákroků 0,895 a 2,68 obdrženého gólu na tým a zápas, což je věrohodné. Kurzy zatím žádné. Sběr trval ~25 min (1,5 s mezi požadavky).

## Spuštění

```
make db                                       # lokální Postgres (compose.yml)
cp .env.example .env && set -a && . ./.env && set +a
go run ./cmd/ingest-hockey migrate
go run ./cmd/ingest-hockey leagues            # s klíči: dohledá API id lig a vypíše je do configu
go run ./cmd/ingest-hockey games              # API-HOCKEY, všechny ligy × sezony z configu
go run ./cmd/ingest-hockey swehockey -league swe-allsvenskan   # ~1 200 stránek, ~30 min: přes nohup
go run ./cmd/ingest-hockey oddspapi -league swe-allsvenskan -from 2026-01-01 -to 2026-06-30
go run ./cmd/ingest-hockey report             # → DATA_M0.md
```

Rozpočet API-HOCKEY: `games` = 1 požadavek na ligu a sezonu (7 lig × 4 sezony = 28), `leagues` = 1–3 na ligu. Ukončené sezony se cachují navždy, opakované spuštění nic nestojí.

## Cron (JODA, až po založení datasetu)

```
*/10 * * * *  ingest-hockey snapshot      # T-24h / T-1h / closing, 1 požadavek na ligu a okno
0 6 * * *     ingest-hockey games -season <aktuální>
30 6 * * *    ingest-hockey swehockey -league swe-allsvenskan -season <aktuální>
```

Snapshot pustí požadavek jen pro ligu, kde zápas vstoupil do okna a snapshot daného druhu ještě nemá. Nasazení na JODU (dataset `pool/bestbet`, compose, `jodadeploy`) zatím není; rozhodne Olin.

## Další kroky

1. Klíče API-HOCKEY a OddsPapi do `.env`, spustit `leagues`, zapsat id do configu, `games`.
2. Scraper ceskyhokej.cz pro brankáře Maxa ligy (stejné rozhraní jako `internal/swehockey`).
3. Ověřit mapování trhů OddsPapi na prvních reálných odpovědích (`internal/oddspapi`, raw odpovědi jsou v cache).
4. Cron snapshotů co nejdřív: každý den bez něj je ztracená historie kurzů.
